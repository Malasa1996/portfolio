# Портфолио Максима Толстикова

Первая адаптивная вёрстка по Figma, узел `600:51637`.

## Запуск

Требуется Node.js 20+. Внешних npm-зависимостей нет.

```sh
npm run dev
```

Сайт откроется по адресу http://localhost:4173. Готовая статическая версия находится в `dist/` и также открывается напрямую через `dist/index.html`.

## Редактирование

- `build.mjs` — структура страницы и сборка композиций из экспортированного контекста Figma.
- `dist/styles.css` — оформление и адаптивные размеры.
- `dist/app.js` — галереи, диалоги, тема и навигация.
- `dist/motion.css` — наслаивание кейсов, орбиты, раскрытие папки и анимированная пагинация.
- `dist/assets/` — оригинальные локальные изображения и шрифты.
- `reference/` — исходные данные Figma для воспроизводимой сборки.

После изменения структуры: `npm run build`. Команда пересоздаёт `dist/index.html` и `dist/artwork.css`, сохраняя остальные файлы.

Подключены `malasa1308@gmail.com` и `https://t.me/malasa1308`. Файл резюме и ссылка LinkedIn не предоставлены: CV открывает контакты для запроса резюме; LinkedIn пока не выводится. Кнопки проектов открывают просмотр представленных работ. Архивные кейсы требуют дополнительного контента. Даты опыта и образования перенесены из макета без изменений.

Галереи переключаются каждые 15 секунд, пока видны на экране. Активная точка заполняется синхронно с таймером. После последнего слайда следует первый, доступны свайп, стрелки клавиатуры и кнопка паузы. В скрытой вкладке и открытом диалоге таймер останавливается. Фокус с клавиатуры в галерее также приостанавливает таймер для чтения.

Картинки в образовании проходят полную орбиту за 70 секунд. Карточка Совкомбанка накладывается на закреплённую карточку Дизайнерс при прокрутке. Папка раскрывается при наведении или фокусе с клавиатуры; клик открывает архив. Исходный SVG папки сохранён. Его контур используется для маски, шум дополнен отдельным SVG, а стекло включает размытую копию исходных слоёв для стабильного отображения внутри контекстов наложения браузера. `prefers-reduced-motion` отключает орбиты и движение при прокрутке, по умолчанию ставит галереи на паузу.
