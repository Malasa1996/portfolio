# Портфолио Максима Толстикова

Первая адаптивная вёрстка по Figma, узел `600:51637`.

## Запуск

Требуется Node.js 20+. Перед первой сборкой выполните `npm ci`: Three.js и esbuild закреплены в lock-файле. На сайте движок и декодер загружаются локально, без CDN.

```sh
npm run dev
```

Сайт откроется по адресу http://localhost:4173. Готовая статическая версия находится в `dist/`; для 3D нужен HTTP-сервер.

## Редактирование

- `build.mjs` — структура страницы и сборка композиций из экспортированного контекста Figma.
- `dist/styles.css` — оформление и адаптивные размеры.
- `dist/app.js` — галереи, смена сцен «Обо мне» от прокрутки, диалоги, тема и навигация.
- `dist/motion.css` — наслаивание кейсов, орбиты, раскрытие папки и анимированная пагинация.
- `dist/stickers.js`, `dist/stickers.css` — интерактивные нижние плашки с гравитацией, вращением и столкновениями. Клик, касание или Enter/Space подбрасывают плашку. Движение останавливается после успокоения тел и при уходе блока за экран.
- `dist/vendor/` — локальная сборка Matter.js 0.20.0 и MIT-лицензия; сайт не загружает физический движок с внешнего CDN.
- `dist/assets/` — оригинальные локальные изображения и шрифты.
- `src/badge-3d.js`, `dist/badge-3d.css` — живая 3D-сцена главного экрана; `dist/badge-3d.js` собирается esbuild. Исходный постер виден до готовности WebGL и возвращается при ошибке.
- `reference/` — исходные данные Figma для воспроизводимой сборки.

После изменения структуры: `npm run build`. Команда пересоздаёт `dist/index.html` и `dist/artwork.css`, сохраняя остальные файлы.

В `dist/assets/badge-3d/` хранится оптимизированный GLB с анимациями и встроенными WebP-текстурами. `reference/export-badge.py` запускается в Blender 5.2 на исходной сцене, `reference/badge_morph.py` сжимает анимацию шнура в PCA-базис с ограниченной погрешностью. Экспорт использует Draco; декодер и лицензия находятся в `dist/vendor/`.

Сохранены камера Blender с lens shift и исходный квадратный кроп постера. Материалы адаптированы к WebGL: печать без дополнительного освещения, прозрачное PET-окно с отражением по краям, процедурные материалы заменены исходной палитрой. Свет и отражения в браузере отличаются от трассировки Cycles. Сцена работает до 30 кадров/с, ограничивает разрешение, приостанавливается вне первого экрана, в скрытой вкладке и при открытом диалоге; `prefers-reduced-motion` оставляет неподвижную модель. Папка сохраняет раскрытие на hover и фокусе. Область обрезания расширяется с запасом для повёрнутых картинок. Портрет в подвале слегка качает головой при наведении мыши и фокусе с клавиатуры: цикл 1,4 с, наклоны до ±5° и кивок на 2 px.
